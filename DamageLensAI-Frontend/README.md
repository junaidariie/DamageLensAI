# DamageLens AI — React Frontend

Dark-themed React frontend for the DamageLens AI FastAPI backend.

## Install & Run

```bash
cd DamageLensAI-Frontend
npm install
npm start
```

App opens at http://localhost:3000

Make sure the FastAPI backend is running first:
```bash
# from DamageLensAI root
uvicorn app:app --reload --host 127.0.0.1 --port 8000
```
